## 素材处理与维护

- 新增视频统一为1280×720、24fps、H.264/yuv420p、无音轨、faststart；每段截取约5–12秒，11段视频合计约10.30MiB。原始文件不改动。
- 画面延用页面黑白呈现，配套本地JPEG封面；只加载当前场景视频，其余场景只使用封面，未预加载全部视频。
- 标题、说明、编号、输入提示和进入对话时的默认问题由同一场景记录更新。编号自动使用总数，不写死为04。保留右侧场景与左侧输入布局，直接进入箭头保留。
- 完整素材记录在 assets/media-sources.json；最初四段保留原Mixkit来源与许可，新增素材记录用户提供的原文件名、裁切参数与许可元数据状态，没有根据文件名推断作者或授权。
- 场景定义集中在 landing-scenes.mjs。每条新增问题均验证演示检索能返回相关条目，未增加新的模型能力或伪造个性化回复。后端接入继续接收普通query即可。
- 集成静态构建从素材清单复制场景，新增场景时同步添加媒体清单；测试校验场景ID、视频、封面、字节数和打包集合一致。

## 前端验收

1440×900与1280×720逐个切换15场景，共30次真实媒体加载/播放检查。检查编号、标题、输入提示、封面、静音播放、无横向溢出、输入与入口对齐、上下区域不重叠；键盘末尾/开头循环正确，点击新场景提交对应问题。证据见qa/scenes-15.json。

## 2026-10-16：情境标题对齐与逐字入场

本次基于已合并 PR #7 的主分支 `cf7f28f`，只调整首页情境文字和静态资源版本。保留主分支已修复的账本进度、对话排序与记忆逻辑。

- 标题向左做 `0.035em` 的视觉补偿，使大字号中文字与下方说明的可见左边缘更接近；情境区仍在右侧。
- 参考 React Bits Split Text 的逐字上浮渐显，以原生 Web Animations 实现，无新增 React、GSAP 或运行依赖。标题每字错开 55ms、单字 900ms；说明延后至 300ms 开始，每字错开 24ms、单字 720ms；编号同时轻淡入。
- 首次打开首页、切换情境及从对话返回首页时播放；重复选中当前情境不会重播。快速切换取消上一组动画，离开首页或隐藏页面时清理动画。系统开启减少动态效果时直接展示完整文字。
- 按 Unicode 字素切分，标题和说明保留完整无障碍标签；动画仅改变透明度和位移，静态排版尺寸保持不变。
- 后端 Agent 接手无需增加接口、事件或返回字段。场景数据、默认提问、视频加载、直接进入及草稿行为沿用现有实现。

本次浏览器检查覆盖 1440×900、1280×720 的全部 15 个情境，共 30 组排版对比；另验证首次入场、逐字错开、快速切换、离开/返回首页和动态切换减少动效设置，无脚本错误。验证对象为静态交互预览，不包含真实模型调用。
